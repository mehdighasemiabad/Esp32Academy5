# آکادمی ESP32 | Esp32Academy

اپلیکیشن آفلاین فارسی و تعاملی برای آموزش ESP32 و اینترنت اشیاء در سطح هنرستان. پروژه با Kotlin، Jetpack Compose و Material 3 ساخته شده است (نه اپلیکیشن Python). مشخصات: `compileSdk=35`، `targetSdk=35` و `minSdk=24`.

## ساخت APK

نیازمندی‌ها: JDK 17، دسترسی اینترنت برای دریافت وابستگی‌های Gradle و Android SDK Platform 35. از ریشه پروژه اجرا کنید:

```sh
./gradlew :app:assembleDebug
```

در Windows:

```bat
gradlew.bat :app:assembleDebug
```

خروجی معمول: `app/build/outputs/apk/debug/app-debug.apk`. فایل‌های launcher همراه مخزن هستند و در نبود Gradle نصب‌شده، Gradle 8.9 را از توزیع رسمی دریافت می‌کنند. اولین ساخت به اینترنت نیاز دارد. GitHub Actions همین ساخت را برای push، pull request یا اجرای دستی انجام داده و APK را به‌صورت artifact نگه می‌دارد.

## محتوای آموزشی و اهداف یادگیری

پس از مطالعه و انجام تمرین‌ها، هنرجو می‌تواند خانواده ESP32 و نقش آن در سامانه‌های تعبیه‌شده را معرفی کند؛ GPIO، ADC و ایمنی ۳٫۳ ولت را توضیح دهد؛ ورودی و خروجی را با Arduino C++ برنامه‌ریزی کند؛ برد را به Wi-Fi متصل کرده و وب‌سرور محلی ساده بسازد؛ و دانش خود را با آزمونک تعاملی بسنجد. برنامه شامل صفحه خانه، معرفی، مشخصات/پین‌ها، Wi-Fi/Bluetooth، کاربردهای IoT، نمونه کدهای LED و کلید و ADC و اتصال Wi-Fi و وب‌سرور، آزمونک خودارزیابی، بخش مسابقه و معرفی پدیدآورنده است.

برای هر نمونه ابتدا هدف، سیم‌بندی و محدودیت را بخوانید، قطعات را با تغذیه قطع‌شده متصل کنید، کد را در Arduino IDE و با Arduino core for ESP32 بسازید، برد و پین درست را انتخاب کنید و سپس با منبع تغذیه مناسب آزمایش کنید. شماره GPIO داخلی LED و قابلیت پایه‌ها بین بردها تفاوت دارند. GPIOها ۳٫۳V هستند و نباید مستقیماً ۵V بگیرند. برای برق شهر، رله ایزوله و نظارت فرد متخصص الزامی است.

## انطباق آموزشی و مسابقه «آفرینش هوشمند»

محصول در محور آموزش بردهای توسعه ESP32 و تولید ابزار نرم‌افزاری آموزشی تعاملی قرار می‌گیرد. تجربه شامل اهداف یادگیری، محتوای فنی، مثال‌های مرحله‌به‌مرحله و ارزشیابی تکوینی با بازخورد است. این ساختار برای پشتیبانی از کیفیت تدریس، قابلیت استفاده، تعامل و ارزیابی یادگیری طراحی شده است؛ پذیرش مسابقه یا انطباق کامل یک اثر به‌تنهایی تضمین نمی‌شود و داوری به شواهد تولید واقعی، صحت فنی، منابع و مستندات شرکت‌کننده نیز وابسته است. متن رسمی آخرین دوره و مهلت‌ها را بررسی کنید.

**شفافیت هوش مصنوعی:** شیوه‌نامه بهره‌گیری هدفمند از ابزار هوش مصنوعی و شرح واقعی ابزارها، دستورهای متنی، خروجی‌ها و بازبینی انسانی را لازم می‌داند. این مخزن ادعای استفاده از ابزار مشخص هوش مصنوعی در تولید آن نمی‌کند، زیرا چنین سابقه‌ای در اختیار این بسته نیست. برای ارسال، شرکت‌کنندگان باید این مستندات را با فرایند واقعی خودشان تکمیل کنند و خروجی کد و محتوای علمی را بازبینی و آزمایش نمایند؛ اطلاعات یا شواهد ساختگی اضافه نکنید.

از فایل `SUBMISSION_TEMPLATE.md` برای آماده‌سازی مستندات اثر استفاده کنید. از نام ابزار، prompt، روند تولید، شواهد آزمون و نقش اعضا فقط گزارش واقعی تهیه کنید. منابع رسمی پیشنهادی نیز در انتهای README آمده‌اند.
